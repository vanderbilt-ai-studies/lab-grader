# Instructor guidance for a lab

Copy this file into your private course workspace and adapt it for the assignment. This document clarifies the rubric; it should not introduce hidden requirements.

- **Assignment and rubric:** Names, versions, and file locations.
- **Calibration and version:** Authoritative rules, source versions, and explicit instructor clarifications that supersede earlier wording.
- **Deduction boundaries:** Which criterion owns each kind of gap; when separate deductions are justified; sufficient evidence and partial-credit anchors.
- **Pilot examples:** Instructor/TA-approved criterion scores and reasons, or an explicitly recorded deferral for this run. Keep student examples in the private course workspace.
- **Learning goals:** What students should demonstrate at this point in the course.
- **Acceptable approaches:** Alternatives that deserve credit; which examples are illustrative rather than mandatory.
- **Partial credit:** How to handle incomplete or partly correct work, consistent with the rubric.
- **Common misunderstandings:** Concepts to watch for and any preferred explanations.
- **Course notes:** Relevant days/dates, section titles, and student-accessible links or source files.
- **Course policies:** Applicable late-work, collaboration, tool-use, and submission requirements, if relevant to grading.
- **Feedback preferences:** Desired length, tone, or emphasis.

Leave out policies that do not apply. Identify any change to a published requirement explicitly so the instructor can resolve it before grading.
